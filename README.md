# Memória Viva

Crie a aplicação web responsiva “Memória Viva” conforme solicitado: página inicial, login/cadastro preparado para Supabase Auth, início de conversa por categoria/tema, chat textual de entrevistadora inteligente com 8–15 perguntas adaptadas e opção de gerar conhecimento organizado, tela de resultado com seções e ações, página “Explorar conhecimentos” com dados fictícios. Prepare as estruturas Supabase para users, knowledge_sessions, messages e knowledge_articles. Design moderno, humano, minimalista, inclusivo para pessoas idosas, com tipografia e botões grandes, excelente em celular e desktop. Não implemente áudio, mas estruture para futura expansão.
